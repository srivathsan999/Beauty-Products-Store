# Favicon Files

## favicon.svg
The main favicon file - an SVG version of the Beauty Store logo (accent color rounded square with white "B" letter).

This SVG favicon will scale perfectly at any size and is supported by modern browsers.

## favicon.png (Optional)
For better compatibility with older browsers, you can generate a PNG version from the SVG:
- Recommended sizes: 32x32, 16x16, or multiple sizes in a single .ico file
- Use an online SVG to PNG converter or image editing software
- The design should match: rounded square background (#C65B7C), white "B" letter

Note: The HTML files reference both SVG (primary) and PNG (fallback) favicons for maximum compatibility.
